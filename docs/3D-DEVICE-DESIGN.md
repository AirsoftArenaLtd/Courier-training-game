# Cab and handheld visual design

C-52 is doing, stacked on pushed C-51. The source audit in `review/set-10/c52-source-audit/manifest.json` records the actual inherited instrument/HUD/handheld files. C-51’s complete acceptance is the baseline.

Next implementation: one coherent physical instrument and device appearance, with readable instrument hierarchy, consistent spacing and contrast. Retain all physical control targets, mirrors, navigation/rear-camera mounts, keyboard/remapping routes, translated whole-sentence readings, narration and the gentle first-day guidance. Larger text must wrap without shrinking, and colour-blind and reduced-motion settings must keep working. No shared settings, scoring, save or translation changes without Claude.

Before review: native cab/handheld screenshots, English and Tamil normal/larger layouts, remapped keyboard/narration checks, and the combined fpbench gate with figures in PERF. This initial source audit is not a visual implementation or a performance measurement.

The first implementation replaces the flat gauge strip with two recessed circular dials on the existing two-triangle instrument face. Analytic ticks, seven-segment speed/RPM values, needles and headlight backlighting allocate no texture or timer. Existing translated whole-sentence speed/RPM readings remain. Switch colours use a restrained metal/graphite palette while preserving every physical position and raycast target.

The handheld now has matching High and Low rugged case artwork, including grip ridges, fasteners, a scanner aperture and speaker slots. The old decorative keypad drawings were not controls; the actual numbered choices keep their original hit objects and handlers. Vector choice faces preserve native text sizes, wrapping, disabled states and focus rings. The original input image retains a minimal nonzero alpha so Phaser still admits pointer hit testing. Low still uses no case canvas; High reuses its existing canvas. Page/close cleanup retains the existing shared-texture ownership rules.

The navigation display and transient prompts use the same restrained frame palette. Navigation projection, screen positions, map clipping, road/obstacle shapes, hints, captions and reading-time rules remain. No new text, control, score event, save field, shared setting, downloaded image or additional Three geometry/pass is introduced. Artwork provenance is recorded in ASSETS.

Validation is under way. Twelve cab unit checks pass, including a new texture-free backlighting/no-mission-write/disposal guard. The initial HUD run passes 186 checks before the final control-colour adjustment; final acceptance must rerun against the frozen candidate. The new native test checks instrument pixels and live state, normal/larger English and Tamil layouts in both presets, real pointer choices and remapped keyboard input. Two early native attempts exposed missing lazy RPM state in the test fixture; they are excluded, and the corrected fixture calls the real suspension initializer. Full current-pilot repository/native/resource acceptance and the owner’s Intel FPS check remain separate.
