# પાઇલટ માટે પ્રશિક્ષકની માર્ગદર્શિકા

આ પાનામાં ફક્ત એ જ ભાગો છે જેનો ઉપયોગ પ્રશિક્ષક તાલીમ ખંડમાં કરે છે: સત્ર કેવી રીતે ચલાવવું, કૅબ (અરીસા, સિગ્નલ,
ગિયર, નેવિગેશન, રસ્તાનાં ચિહ્નો), પછીના કામકાજના દિવસો, પરિણામ કેવી રીતે વાંચવાં, અને કંઈક ખોટું થાય ત્યારે શું કરવું.
IT અને સર્વરની ગોઠવણ, ખાતાં, અકાદમીના નિયમો, કંપનીનો દેખાવ, પ્રશિક્ષકનાં સાધનો, LMS અને ડેટાના ભાગો ફક્ત અંગ્રેજી
માર્ગદર્શિકા `docs/PILOT-GUIDE.md` માં છે. છાપવા માટે એક પાનું: `docs/QUICK-START.gu.md`.

**તાલીમાર્થીઓ શું કરે છે.** તેઓ સાઇન ઇન કરે છે, તાલીમ મૉડ્યુલ (છટણી, ઉપાડવું, ડ્રાઇવિંગ, લોડિંગ, સ્ટોપ) નો અભ્યાસ કરે
છે અને તેમાં મૂલ્યાંકન આપે છે, અને એક **કામકાજનો દિવસ** (workday) રમે છે: 3D માં કુરિયરનો આખો દિવસ. તેઓ ડિસ્પેચ પર
સવારની બ્રીફ વાંચે છે, માલને મૅનિફેસ્ટ સાથે મેળવે છે, વૅન લોડ કરે છે, તેની તપાસ કરે છે, ડ્રાઇવ કરે છે, પાંચ સ્ટોપ પર
ડિલિવરી કરે છે (કૂતરા, સહીઓ, ID ની તપાસ, ખોટાં સરનામાં, હવામાન, ડિસ્પેચના સંદેશા), જે પહોંચાડી ન શક્યા તે પાછું આપે છે
અને દિવસ ડિસ્પેચ પર પૂરો કરે છે. સલામતી, કાર્યક્ષમતા અને સેવા, દરેકને 0 થી 3 તારા મળે છે. પહેલો દિવસ સરળ હોય છે અને
એક ટૂંકી માર્ગદર્શિકા (જે **H** થી ફરી ખોલી શકાય છે) નિયંત્રણો સમજાવે છે. પછીના દિવસો વધુ માગે છે: દરેક પાર્સલ પર
સહી, ફોટો ID ની તપાસ, નક્કી સમયપત્રક મુજબ ધુમ્મસ, વરસાદ અને બરફ, અને રસ્તાના કામથી બંધ એક શેરી જેના માટે બીજો રસ્તો
લેવો પડે છે. પછીના દિવસોમાં આયોજનની બારીઓ ફક્ત માર્ગદર્શન છે અને તેના પર ક્યારેય ગુણ મળતા નથી. દિવસના અંતે પરિણામની
સ્ક્રીન આવે છે, પછી એક ડિબ્રીફ જે બતાવે છે કે શું સારું રહ્યું અને શું સુધારવાનું છે, અને એક રેકોર્ડ જે તમે છાપી
શકો છો.

## પહેલા સત્ર પહેલાં

(1 થી 4: IT, ખાતાં, અકાદમીના નિયમો, કંપનીનો દેખાવ; અંગ્રેજી માર્ગદર્શિકા જુઓ.)

**5. ભાષા અને સુવિધા.** દરેક તાલીમાર્થી **સેટિંગ્સ → ઍક્સેસિબિલિટી** (Settings → Accessibility) માં પોતાની ભાષા, મોટું
લખાણ, રંગઅંધત્વ માટેની સેટિંગ, કીની નવી ગોઠવણ, ઓછી હલચલ અને નરેશન પસંદ કરી શકે છે. અવાજ (એન્જિન, ઇન્ડિકેટર, દરવાજા,
સ્કૅન, વરસાદ) નું વૉલ્યૂમ અને મ્યૂટ છે (સ્પીકરનું બટન કે પૉઝ મેનૂ); દરેક અવાજનું લખાણમાં કૅપ્શન પણ છે, અને નરેશન બોલતું
હોય ત્યારે અવાજ અટકે છે, તેથી રમવા માટે કોઈએ તે સાંભળવાની જરૂર નથી. જો કોઈ PC પર 3D અટકતું હોય, તો
**સેટિંગ્સ → ગ્રાફિક્સ → ઓછા ગ્રાફિક્સ** (Settings → Graphics → Low) પસંદ કરો. માતૃભાષીઓ સમીક્ષા ન કરે ત્યાં સુધી અનુવાદો
મશીનના મુસદ્દા છે (`docs/review/`); તાલીમાર્થીઓને કહો કે જે શબ્દો ખોટા લાગે તેની જાણ કરે.

**6. ગેમપૅડ.** 3D દુનિયામાં સામાન્ય (સ્ટાન્ડર્ડ) ગેમપૅડ પણ ચાલે છે: તેનું એક બટન દબાવો, પછી બધાં નિયંત્રણો છોડી દો.
**Esc → નિયંત્રણો અને માર્ગદર્શન → ગેમપૅડ નિયંત્રણો** બતાવે છે કે દરેક બટન શું કરે છે, અને તાલીમાર્થી કોઈ પણ બટન બદલી
શકે છે અથવા સ્ટિકની સંવેદનશીલતા બદલી શકે છે; તેમની પસંદગી તેમની પ્રગતિ સાથે સચવાય છે. કીબોર્ડ અને માઉસ ચાલુ રહે છે.

**7. 3Dમાં મોડ્યુલ.** કેટલાક તાલીમ મોડ્યુલ 3D દુનિયામાં પણ રમી શકાય છે: હાલ રૂટ અને ડ્રાઇવિંગ, બાકીના તૈયાર થાય તેમ વધુ.
**સેટિંગ્સ → પ્રશિક્ષક → 3D કામકાજના દિવસની સહાય… → 3Dમાં મોડ્યુલ…** દરેક મોડ્યુલ માટે **તૈયાર થાય ત્યારે** (તપાસ પસાર
કર્યા પછી 3D સંસ્કરણ, નહીં તો 2D; આ મૂળ સેટિંગ છે), **3D** કે **2D** પસંદ કરે છે; પછી **નિયમો સેવ કરો** દબાવો. 3D
ગ્રાફિક્સ વિનાનું પીસી હંમેશાં 2D ચલાવે છે. બંનેમાં તારા, રેકોર્ડ અને પ્રમાણપત્ર સરખાં છે.

**ડ્રાઇવ કરતાં પહેલાં, કૅબ.** 3D વૅનની કૅબ સાચી વૅનની જેમ કામ કરે છે, અને તે એક મિનિટ બતાવવી યોગ્ય છે:

- **અરીસા** હંમેશાં ચાલુ અને હંમેશાં જીવંત હોય છે. અરીસાનું કોઈ બટન નથી: તાલીમાર્થી અરીસા તરફ થોડી ક્ષણ *જોઈને* તેને
  તપાસે છે. ચાલતાં પહેલાં તરત ડાબો અરીસો તપાસવાનો હોય છે, અને સ્ટિયરિંગ ફેરવતાં પહેલાં તરત જે બાજુ વળે છે કે લેન બદલે
  છે તે બાજુનો અરીસો (એક તપાસ લગભગ ચાર સેકન્ડ સુધી માન્ય રહે છે). દરેક તપાસ પરિણામમાં નોંધાય છે, અને ચૂકી ગયેલી તપાસ
  ડ્રાઇવના નકશા પર એક પિન બને છે.
- **સિગ્નલ** (B-138): ડાબે માટે Q, જમણે માટે C, અથવા સ્ટિયરિંગ પાસેનું લીવર. કોઈ સ્ટોપ પછી વૅન ચાલે તે પહેલાં (પાછળ
  જતાં પણ) અને વળતાં પહેલાં ઇન્ડિકેટર સાચી દિશામાં ઓછામાં ઓછું ત્રણ સેકન્ડ ચાલુ હોવું જોઈએ; પછી અરીસાની તપાસ. સિગ્નલ
  ન આપવો કે મોડો આપવો ડ્રાઇવના નકશા પર એક પિન છે. ઇન્ડિકેટર આપમેળે બંધ થતું નથી: કી ફરી દબાવો.
- **ગિયર** એટલે સ્ટિયરિંગ પાસેનું P-R-N-D સિલેક્ટર: તેની તરફ જુઓ અને ઍક્શન કી (E) દબાવો, અથવા Drive અને Reverse વચ્ચે
  બદલવા R દબાવો. ગિયર બદલવા માટે વૅન ઊભી હોવી જોઈએ.
- **રિવર્સ કરવું:** R પસંદ કરતાં જ ડૅશબોર્ડ પર પાછળના કૅમેરાની સ્ક્રીન આપમેળે ચાલુ થાય છે. તેની માર્ગદર્શક રેખાઓ
  સ્ટિયરિંગ સાથે વળે છે, અને રંગીન અંતરનાં નિશાન, સેન્સરના પટ્ટા, લખેલું અંતર અને હળવી બીપ પાછળની કોઈ પણ વસ્તુ વિશે
  ચેતવે છે. તાલીમાર્થીઓએ ઊતરીને જોવાની જરૂર નથી; તેમણે ચાલવાની ઝડપે રિવર્સ કરવું અને જોતા રહેવું જોઈએ. ટક્કર, કે
  રિવર્સમાં 5 mph થી વધુ ઝડપ, પરિણામમાં નોંધાય છે. 3D મેનૂ (H) માં
  **રિવર્સ કરવાની જગ્યા પસંદ કરો** (Choose a reversing space) કામકાજના દિવસ પર અસર કર્યા વિના એકલા અભ્યાસ માટે એક ગલી,
  એક લોડિંગ ડૉક અને એક સાંકડો ડ્રાઇવવે આપે છે.
- ડૅશબોર્ડ પરનું **નેવિગેશન** (sat nav) રૂટ, આગળનો વળાંક, કેટલું દૂર અને શેરીનું નામ બતાવે છે. વળાંક ચૂકી જાઓ તો રૂટ
  ફરી બને છે, અને રૂટ છોડ્યું ગણાય તે પહેલાં તાલીમાર્થી પાસે પાછા આવવા માટે 30 સેકન્ડ હોય છે.
  **3D કામકાજના દિવસની સહાય…** (3D workday aids…) તેને પૂરો નકશો, ફક્ત રૂટની રેખા, અથવા બંધ પર સેટ કરે છે.
- **રસ્તાનાં ચિહ્નો** ત્યાં જ છે જ્યાં કોઈ શહેરમાં હોય: ખૂણા પર શેરીનાં નામ, ઘરના નંબર, સ્ટોપ અને રસ્તો આપો ચિહ્નો, ઝડપ
  મર્યાદા, શાળા વિસ્તાર, એકમાર્ગી અને પ્રવેશ નિષેધવાળી શેરીઓ, રસ્તાનું કામ અને ટ્રાફિક લાઇટ. **J** સામે દેખાતું ચિહ્ન
  મોટેથી વાંચે છે (નરેશન વાપરતા તાલીમાર્થીઓ માટે). દરેક ચિહ્ન એક તપાસ છે: પૂરેપૂરું ઊભા રહેવું, રસ્તો આપવો, ઝડપ મર્યાદામાં
  રહેવું, લાલ લાઇટ પર ઊભા રહેવું (લાલ લાઇટ તોડવી કે પ્રવેશ નિષેધવાળી શેરીમાં ઘૂસવું ગંભીર ભૂલ છે).
- **બાકીનું બધું વૅનમાં જ્યાં હોય ત્યાં જ છે:** પાર્કિંગ બ્રેક (Space કે લીવર), સીટબેલ્ટ (B કે બકલ), ઇન્ડિકેટર (Q અને C કે
  લીવર), હેડલાઇટ (L) અને વાઇપર (K). P વારાફરતી દરેક નિયંત્રણ તરફ નજર ફેરવે છે અને તે શું કરે છે તે કહે છે, જેથી જે
  તાલીમાર્થી માઉસ વાપરી શકતો નથી તે આ બધું કીબોર્ડથી કરી શકે.

**દિવસ કેવો દેખાય છે.** શહેર, વૅન અને લોકો હવે 3D મૉડલ છે (મફત CC0 મૉડલ; તેમના બનાવનારાઓનો આભાર ટાઇટલ સ્ક્રીન પરના
**શ્રેય** (Credits) માં માન્યો છે). દરેક કામકાજના દિવસનો પોતાનો સમય અને હવામાન હોય છે, તેથી તાલીમાર્થીઓને કહો કે શું
અપેક્ષા રાખવી:

- **દિવસનો સમય:** સવાર, બપોર, સંધ્યા કે રાત. સંધ્યાએ અને રાત્રે કૅબ તાલીમાર્થીને ચાલતાં પહેલાં હેડલાઇટ ચાલુ કરવા કહે છે
  (L, કે લાઇટની સ્વિચ). રાત્રિના રન **3D કામકાજના દિવસની સહાય…** (3D workday aids…) માં બંધ કરી શકાય છે.
- **હવામાન:** વિન્ડસ્ક્રીન પર વરસાદ (વાઇપર તેને સાફ કરે છે: K, કે લીવર), અંતર છુપાવતું ધુમ્મસ, હિમવર્ષા અને બરફ. હવામાન
  નિયમો બદલતું નથી; તે ફક્ત તાલીમાર્થી શું જુએ છે અને કેટલે આગળ સુધી જોઈ શકે છે તે બદલે છે: પરિસ્થિતિ પ્રમાણે ડ્રાઇવ કરો.
- **લોકો:** રહેવાસીઓ દરવાજે આવે છે અને કુરિયર ઍનિમેટેડ છે; તેમના વિશેની કોઈ પણ બાબત પર ગુણ મળતા નથી.

**ત્રીજા કામકાજના દિવસથી** સ્ટોપ વધુ વૈવિધ્યપૂર્ણ બને છે. ઘણા સ્ટોપ પર **પાર્સલ લૉકર** હોય છે (સાચું ખાનું ખોલો, સ્કૅન
કરો, પાર્સલ અંદર મૂકો, બંધ કરો, બંધ દરવાજાનો ફોટો લો), કેટલાક પર **ઍપાર્ટમેન્ટનું ઇન્ટરકૉમ** (સાચા ફ્લૅટનું બટન, તમે કોણ
છો તે કહો, બઝરની રાહ જુઓ; તાળું ખૂલે નહીં ત્યાં સુધી ગેટ બંધ રહે છે), અને થોડા પર **કોઈ વ્યવસાયનું રિસેપ્શન** (સરનામું
પાકું કરો, વ્યક્તિનું નામ અને સહી લો). સહી જરૂરી હોય તેવા પાર્સલ માટે કોઈ ઘરે ન હોય, ત્યારે તાલીમાર્થી
**નિષ્ફળ ડિલિવરી** નોંધે છે: એક કાર્ડ, કારણ, બીજા દિવસે બપોર પછીનો એક સમય, અને પાર્સલ રિટર્ન્સમાં પાછું જાય છે.

**ચોથા કામકાજના દિવસથી** દિવસ તાલીમાર્થી પાસેથી હજી વધુ માગે છે:

- **વૅનની ચારે બાજુ ફરીને તપાસ.** પહેલી ડ્રાઇવ પહેલાં (મુસાફરી પહેલાંની તપાસ), તાલીમાર્થી ઊભી વૅનની ચારે બાજુ ફરે છે
  અને સાત ભાગોની સ્થિતિ નોંધે છે (આગળ, પાછળ, બંને બાજુ, છતની કિનારી, પાછળનું ડાબું પૈડું અને ડાબો અરીસો): P કોઈ ભાગનું
  નિશાન પસંદ કરે છે, E તેને તપાસે છે, અને હૅન્ડહેલ્ડ શું દેખાય છે તે બતાવે છે. જે ઘસારો પહેલેથી હતો તેનો દોષ તેમના પર
  ક્યારેય આવતો નથી. ડેપો પર પાછા આવીને તેઓ **કામકાજનો દિવસ પૂરો કરો** (Finish workday) પહેલાં ફરી ચક્કર લગાવે છે અને કોઈ
  પણ નવું નુકસાન બરાબર જ્યાં છે ત્યાં નોંધે છે.
- **નુકસાન અને ઓછી ઊંચાઈ.** કોઈ થાંભલા, પાર્ક કરેલી કાર કે બોલાર્ડ સાથે ઘસાવાથી વૅન પર બરાબર એ જ જગ્યાએ નિશાન પડે છે:
  ઘસરકો, ગોબો કે મોટું નુકસાન (મોટું નુકસાન ગંભીર ભૂલ છે). નીચા પુલ અને બહાર નીકળેલાં માળખાં પર ઊંચાઈનાં ચિહ્નો છે, જે
  વૅનની ઊંચાઈ સાથે મેળવવાનાં હોય છે; સાચો જવાબ છે ઊભા રહેવું કે બીજી શેરી લેવી. **તાલીમાર્થીએ કરેલું અને ટ્રિપ પછી ન
  નોંધેલું નુકસાન ગંભીર ભૂલ છે**, કારણ કે પછીના ડ્રાઇવરને તે વારસામાં મળે છે. જે નુકસાન છે જ નહીં તે નોંધવાથી પણ ગુણ
  કપાય છે.
- **ડિસ્પેચ રેડિયો** (the dispatch radio). પહેલી ડ્રાઇવમાં લગભગ વીસ મીટર પછી ડિસ્પેચ એક વાર કૉલ કરે છે. કૅપ્શન તે જણાવે
  છે; તાલીમાર્થી ઊભો રહે છે, પાર્કિંગ બ્રેક લગાવે છે અને સંદેશ હૅન્ડહેલ્ડ પર વાંચે છે (વૅન ઊભી ન રહે ત્યાં સુધી સંદેશ રાહ
  જુએ છે). બેકી દિવસોએ તે એક ડિલિવરી વહેલી કરાવે છે, એકી દિવસોએ રસ્તામાં કોઈ પાર્કિંગની જગ્યાએ ચેક-ઇન કરવા કહે છે. તેનું
  પાલન સેવામાં ગણાય છે; ના પાડવી કે અવગણવું એ ચૂકી ગયેલું અપડેટ છે, પણ તેનાથી દિવસ પૂરો કરવાનું ક્યારેય અટકતું નથી.
- **રાત.** છઠ્ઠા દિવસથી દર ત્રીજો દિવસ અંધારું થયા પછી ચાલે છે. હેડલાઇટ વગર વૅન ચાલે તે પહેલાં કૅબ ચેતવણી આપે છે, અને
  અંધારામાં હેડલાઇટ વગર ચલાવેલો દરેક ભાગ સલામતીની વિરુદ્ધ ગણાય છે. સામેથી આવતી હેડલાઇટ થોડી ચમક આપે છે, જેને ઓછી હલચલ
  દૂર કરે છે (3D દુનિયામાં **Esc** →
  **સેટિંગ્સ → ઍક્સેસિબિલિટી → ઓછી હલચલ ચાલુ કરો** (Settings → Accessibility → Turn reduced motion on), અથવા PC ની પોતાની
  ઓછી હલચલની સેટિંગ).

રાત્રિના રન અને વૅનનું નુકસાન (તેની ચારે બાજુની તપાસના અહેવાલો સાથે), બંનેને અલગ અલગ
**3D કામકાજના દિવસની સહાય…** (3D workday aids…) માં બંધ કરી શકાય છે, ઉદાહરણ તરીકે એવા જૂથના પહેલા સત્ર માટે જેણે ક્યારેય
વૅન ચલાવી નથી.

આ બધાની સાથે કોઈ PC ધીમું હોય, તો **સેટિંગ્સ → ગ્રાફિક્સ → ઓછા ગ્રાફિક્સ** (Settings → Graphics → Low) ઓછું દોરે છે અને
દિવસ એ જ રાખે છે.

અભ્યાસ મૉડ્યુલ અને મૂલ્યાંકન કામકાજના દિવસ પહેલાં કે પછી થઈ શકે છે. એક સારો ક્રમ આ છે: કંપની માટે સૌથી મહત્ત્વનાં
મૉડ્યુલ પર એક અભ્યાસ સત્ર, પછી કામકાજનો દિવસ, પછી મૂલ્યાંકન.

## પરિણામ વાંચવાં

**તાલીમાર્થીની સ્ક્રીન પર**
- **પરિણામ** (Results): સલામતી, કાર્યક્ષમતા અને સેવામાં તારા, અને સ્કોર.
- **ડિબ્રીફ** (Debrief): દરેક સ્ટોપ, શું સાચું કે ખોટું થયું અને શા માટે. ગંભીર ભૂલો (જેમ કે લાઇટ ઝબકાવતી સ્કૂલ બસની
  બાજુમાંથી પસાર થઈ જવું, કે ID તપાસ્યા વિના ઉંમર-મર્યાદાવાળું પાર્સલ કોઈને આપી દેવું) બાકીનું બધું ગમે તેટલું સારું રહ્યું
  હોય, તે શ્રેણીને એક તારા સુધી મર્યાદિત કરે છે.
- **ડ્રાઇવનો નકશો** (Drive map): જ્યાં જ્યાં ડ્રાઇવિંગની ભૂલ થઈ ત્યાં એક પિન, પાઠ સાથે.
- **છેલ્લી ભૂલ ફરી ચલાવો** (Replay the last mistake) (3D કામકાજના દિવસ પછી, પરિણામ અને ડ્રાઇવના નકશા પર): સૌથી તાજેતરની
  ભૂલ પહેલાંની છેલ્લી થોડી સેકન્ડ, ડ્રાઇવરની સીટ પરથી, ચલાવવા, અટકાવવા અને અડધી-અડધી સેકન્ડ આગળ વધવાની સુવિધા સાથે. તે
  ફક્ત બ્રાઉઝરની મેમરીમાં રહે છે, તેથી ટૅબ બંધ થતાં કે બીજો કામકાજનો દિવસ શરૂ થતાં જ જતું રહે છે, અને તેમાંનું કંઈ સેવ
  થતું નથી કે તેના પર ગુણ મળતા નથી.
- **મારો રેકોર્ડ ›** (My record ›): દરેક મૉડ્યુલ, તારીખો અને વારંવાર પાછા આવતા પાઠ. **પ્રિન્ટ / PDF** (Print / PDF) ફાઇલમાં
  રાખવા માટે પાનું આપે છે.

પ્રશિક્ષકનાં સાધનો (**સેટિંગ્સ → પ્રશિક્ષક** (Settings → Trainer): ફરી પ્રયાસની મંજૂરી, રીસેટ, પહેલાં અને પછી, પ્રમાણપત્ર,
તેમનો ડેટા) અને LMS વાળો ભાગ અંગ્રેજી માર્ગદર્શિકામાં છે.

## જ્યારે કંઈક ખોટું થાય

| તમે શું જુઓ છો | શું કરવું |
| --- | --- |
| તાલીમાર્થી સાઇન ઇન કરી શકતો નથી | કર્મચારી ID તપાસો (નાના-મોટા અક્ષરથી ફરક પડતો નથી). પાંચ ખોટા પ્રયાસથી તે 15 મિનિટ માટે લૉક થાય છે; **વ્યવસ્થા → નવો પાસવર્ડ** (Manage → New password) તેને તરત ખોલે છે. |
| ગેમ શરૂ થતી નથી, કે "WebGL is required" | ગ્રાફિક્સ ઍક્સિલરેશન બંધ છે કે અટકાવેલું છે. `chrome://gpu` (Edge: `edge://gpu`) ખોલો અને "WebGL: Hardware accelerated" શોધો. IT ને તે ચાલુ કરવા કહો; **સેટિંગ્સ → ગ્રાફિક્સ → ઓછા ગ્રાફિક્સ** (Settings → Graphics → Low) અજમાવો. |
| 3D ધીમું છે કે અટકે છે | **સેટિંગ્સ → ગ્રાફિક્સ → ઓછા ગ્રાફિક્સ** (Settings → Graphics → Low); બીજી વિન્ડો અને ટૅબ બંધ કરો; લૅપટૉપ ચાર્જરમાં લગાવો. ગેમ જાળવણીકારને PC નું મૉડલ જણાવો: પાઇલટ સાચાં PC માપે છે. |
| ગેમપૅડથી કંઈ થતું નથી | 3D દુનિયા ખુલ્લી રાખીને તેનું એક બટન દબાવો, પછી બધાં નિયંત્રણો છોડી દો. બ્રાઉઝર જેને સ્ટાન્ડર્ડ ગણે તે જ ગેમપૅડ ચાલે છે; કીબોર્ડ અને માઉસ હંમેશાં ચાલે છે. **ગેમપૅડ નિયંત્રણો → ગેમપૅડના મૂળ નિયંત્રણો પાછા લાવો** બદલેલાં બટન પાછાં મૂળ પર લાવે છે. |
| પ્રગતિ ખોવાઈ ગઈ લાગે છે | તાલીમ સર્વર પર તે દરેક કર્મચારી ID પ્રમાણે રખાય છે: તપાસો કે તેમણે એ જ ID થી સાઇન ઇન કર્યું હતું. ફક્ત-બ્રાઉઝર મોડમાં પ્રગતિ એ જ બ્રાઉઝરમાં રહે છે અને તેનો સાઇટ ડેટા સાફ કરવાથી ભૂંસાઈ જાય છે. |
| કોઈ ભાષામાં લખાણ ખોટું દેખાય છે | સ્ક્રીન અને લખાણ નોંધો; સુધારા `docs/review/` માંની માતૃભાષી સમીક્ષાની શીટમાં જાય છે. |
| તાલીમાર્થી પોતાનો ડેટા દૂર કરાવવા માગે છે | **સેટિંગ્સ → પ્રશિક્ષક** (Settings → Trainer) → તે તાલીમાર્થી → **તેમનો ડેટા** (Their data). |
| સર્વર બંધ છે | તાલીમાર્થીઓ રમતા રહી શકે છે: પ્રગતિ તેમના PC પર રહે છે અને સર્વર જવાબ આપે ત્યારે મોકલાય છે. IT ને `node server/server.js` રીસ્ટાર્ટ કરવા કહો; કશું ખોવાતું નથી. |
