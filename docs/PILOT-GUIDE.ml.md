# പൈലറ്റിനുള്ള പരിശീലകന്റെ ഗൈഡ്

പരിശീലകൻ പരിശീലന മുറിയിൽ ഉപയോഗിക്കുന്ന ഭാഗങ്ങൾ മാത്രമാണ് ഈ പേജിലുള്ളത്: സെഷൻ എങ്ങനെ നടത്താം, ക്യാബ് (കണ്ണാടികൾ,
സിഗ്നലുകൾ, ഗിയറുകൾ, സാറ്റ് നാവ്, റോഡ് അടയാളങ്ങൾ), പിന്നീടുള്ള ജോലിദിനങ്ങൾ, ഫലങ്ങൾ എങ്ങനെ വായിക്കാം, എന്തെങ്കിലും
പ്രശ്നമുണ്ടായാൽ എന്തു ചെയ്യണം. IT, സെർവർ സജ്ജീകരണം, അക്കൗണ്ടുകൾ, അക്കാദമി നിയമങ്ങൾ, കമ്പനിയുടെ രൂപം, പരിശീലകന്റെ
ഉപകരണങ്ങൾ, LMS, ഡാറ്റ എന്നീ ഭാഗങ്ങൾ ഇംഗ്ലീഷ് ഗൈഡായ `docs/PILOT-GUIDE.md`-ൽ മാത്രമാണുള്ളത്. പ്രിന്റ് ചെയ്യാൻ ഒരു പേജ്:
`docs/QUICK-START.ml.md`.

**പരിശീലനാർഥികൾ എന്തു ചെയ്യുന്നു.** അവർ സൈൻ ഇൻ ചെയ്യുന്നു, പരിശീലന മൊഡ്യൂളുകളിൽ (തരംതിരിക്കൽ, ഉയർത്തൽ, ഡ്രൈവിങ്,
ലോഡിങ്, സ്റ്റോപ്പുകൾ) പരിശീലിക്കുകയും വിലയിരുത്തപ്പെടുകയും ചെയ്യുന്നു, ഒരു **ജോലിദിനം** (workday) കളിക്കുന്നു: 3D-യിൽ
ഒരു കൊറിയറുടെ മുഴുവൻ ദിവസം. അവർ ഡിസ്പാച്ചിൽ രാവിലത്തെ ബ്രീഫ് വായിക്കുന്നു, ചരക്ക് മാനിഫെസ്റ്റുമായി ഒത്തുനോക്കുന്നു,
വാൻ ലോഡ് ചെയ്യുന്നു, അത് പരിശോധിക്കുന്നു, ഡ്രൈവ് ചെയ്യുന്നു, അഞ്ച് സ്റ്റോപ്പുകളിൽ ഡെലിവറി ചെയ്യുന്നു (നായ്ക്കൾ, ഒപ്പുകൾ,
ID പരിശോധന, തെറ്റായ വിലാസങ്ങൾ, കാലാവസ്ഥ, ഡിസ്പാച്ചിൽനിന്നുള്ള സന്ദേശങ്ങൾ), എത്തിക്കാൻ കഴിയാത്തവ തിരികെ നൽകുന്നു,
ദിവസം ഡിസ്പാച്ചിൽ അവസാനിപ്പിക്കുന്നു. സുരക്ഷ, കാര്യക്ഷമത, സേവനം എന്നിവ ഓരോന്നിനും 0 മുതൽ 3 വരെ നക്ഷത്രങ്ങൾ ലഭിക്കുന്നു.
ആദ്യ ദിവസം എളുപ്പമാണ്; ഒരു ചെറിയ ഗൈഡ് (**H** ഉപയോഗിച്ച് വീണ്ടും തുറക്കാം) നിയന്ത്രണങ്ങൾ വിശദീകരിക്കുന്നു. പിന്നീടുള്ള
ദിവസങ്ങൾ കൂടുതൽ ആവശ്യപ്പെടുന്നു: ഓരോ പാഴ്സലിനും ഒപ്പ്, ഫോട്ടോ ID പരിശോധന, നിശ്ചിത സമയക്രമമനുസരിച്ച് മൂടൽമഞ്ഞ്, മഴ,
മഞ്ഞുപാളി, റോഡ് പണി കാരണം അടച്ചതും വഴിമാറ്റമുള്ളതുമായ ഒരു തെരുവ്. പിന്നീടുള്ള ദിവസങ്ങളിലെ ആസൂത്രണ ജാലകങ്ങൾ മാർഗനിർദേശം
മാത്രമാണ്; അവയ്ക്ക് ഒരിക്കലും പോയിന്റ് ലഭിക്കില്ല. ദിവസം ഒരു ഫല സ്ക്രീനോടെ അവസാനിക്കുന്നു, തുടർന്ന് എന്ത് നന്നായി,
എന്ത് തിരുത്തണം എന്ന് കാണിക്കുന്ന ഒരു ഡീബ്രീഫ്, നിങ്ങൾക്ക് പ്രിന്റ് ചെയ്യാവുന്ന ഒരു റെക്കോർഡ്.

## ആദ്യ സെഷനു മുമ്പ്

(1 മുതൽ 4 വരെ: IT, അക്കൗണ്ടുകൾ, അക്കാദമി നിയമങ്ങൾ, കമ്പനിയുടെ രൂപം; ഇംഗ്ലീഷ് ഗൈഡ് കാണുക.)

**5. ഭാഷയും സൗകര്യവും.** ഓരോ പരിശീലനാർഥിക്കും **ക്രമീകരണങ്ങൾ → ആക്സസിബിലിറ്റി** (Settings → Accessibility)-ൽ തന്റെ
ഭാഷ, വലിയ അക്ഷരം, വർണാന്ധതയ്ക്കുള്ള ക്രമീകരണം, കീകളുടെ പുനഃക്രമീകരണം, കുറഞ്ഞ ചലനം, വിവരണം എന്നിവ തിരഞ്ഞെടുക്കാം.
ശബ്ദത്തിന് (എഞ്ചിൻ, ഇൻഡിക്കേറ്ററുകൾ, വാതിലുകൾ, സ്കാനുകൾ, മഴ) വോളിയവും മ്യൂട്ടും ഉണ്ട് (സ്പീക്കർ ബട്ടൺ അല്ലെങ്കിൽ പോസ്
മെനു); ഓരോ ശബ്ദത്തിനും ഒരു എഴുത്ത് അടിക്കുറിപ്പും ഉണ്ട്, വിവരണം സംസാരിക്കുമ്പോൾ ശബ്ദം നിൽക്കും; അതിനാൽ കളിക്കാൻ ആരും
അത് കേൾക്കേണ്ടതില്ല. ഏതെങ്കിലും PC-യിൽ 3D ഇടറുന്നുവെങ്കിൽ,
**ക്രമീകരണങ്ങൾ → ഗ്രാഫിക്സ് → കുറഞ്ഞ ഗ്രാഫിക്സ്** (Settings → Graphics → Low) തിരഞ്ഞെടുക്കുക. മാതൃഭാഷക്കാർ പരിശോധിക്കുന്നതുവരെ
വിവർത്തനങ്ങൾ യന്ത്രം തയ്യാറാക്കിയ കരടുകളാണ് (`docs/review/`); തെറ്റായി തോന്നുന്ന വാക്കുകൾ അറിയിക്കാൻ പരിശീലനാർഥികളോട്
പറയുക.

**ഡ്രൈവ് ചെയ്യുന്നതിനു മുമ്പ്, ക്യാബ്.** 3D വാനിന്റെ ക്യാബ് യഥാർഥ വാനിന്റേതുപോലെ പ്രവർത്തിക്കുന്നു; ഒരു മിനിറ്റ് അത്
കാണിച്ചുകൊടുക്കുന്നത് ഗുണം ചെയ്യും:

- **കണ്ണാടികൾ** എപ്പോഴും ഓണാണ്, എപ്പോഴും തത്സമയവുമാണ്. കണ്ണാടിക്ക് ബട്ടൺ ഇല്ല: പരിശീലനാർഥി ഒരു നിമിഷം കണ്ണാടിയിലേക്ക്
  *നോക്കി* അത് പരിശോധിക്കുന്നു. നീങ്ങുന്നതിന് തൊട്ടുമുമ്പ് ഇടത് കണ്ണാടി പരിശോധിക്കണം, സ്റ്റിയറിങ് തിരിക്കുന്നതിന് തൊട്ടുമുമ്പ്
  തിരിയുന്ന അല്ലെങ്കിൽ ലെയ്ൻ മാറുന്ന വശത്തെ കണ്ണാടിയും (ഒരു പരിശോധന ഏകദേശം നാല് സെക്കൻഡ് സാധുവാണ്). ഓരോന്നും ഫലങ്ങളിൽ
  രേഖപ്പെടുത്തും; വിട്ടുപോയ പരിശോധന ഡ്രൈവ് മാപ്പിൽ ഒരു പിൻ ആകും.
- **സിഗ്നലുകൾ** (B-138): ഇടത്തേക്ക് Q, വലത്തേക്ക് C, അല്ലെങ്കിൽ സ്റ്റിയറിങ്ങിനടുത്തുള്ള ലിവർ. ഒരു സ്റ്റോപ്പിനു ശേഷം വാൻ
  നീങ്ങുന്നതിനു മുമ്പും (പിന്നോട്ടാണെങ്കിലും) തിരിയുന്നതിനു മുമ്പും ഇൻഡിക്കേറ്റർ ശരിയായ ദിശയിൽ കുറഞ്ഞത് മൂന്ന് സെക്കൻഡ്
  ഓണായിരിക്കണം; പിന്നെ കണ്ണാടി പരിശോധന. സിഗ്നൽ നൽകാതിരിക്കുന്നതോ വൈകി നൽകുന്നതോ ഡ്രൈവ് മാപ്പിൽ ഒരു പിൻ ആണ്.

  അടിക്കുറിപ്പ് അത് അറിയിക്കും; പരിശീലനാർഥി നിർത്തി, പാർക്കിംഗ് ബ്രേക്ക് ഇട്ട്, സന്ദേശം ഹാൻഡ്‌ഹെൽഡിൽ വായിക്കുന്നു (വാൻ
  നിർത്തിയിടുന്നതുവരെ സന്ദേശം കാത്തിരിക്കും). ഇരട്ട ദിവസങ്ങളിൽ ഇത് ഒരു ഡെലിവറി നേരത്തെയാക്കുന്നു, ഒറ്റ ദിവസങ്ങളിൽ
  വഴിയിലെ ഒരു പാർക്കിംഗ് സ്ഥലത്ത് ചെക്ക്-ഇൻ ചെയ്യാൻ ആവശ്യപ്പെടുന്നു. അത് പാലിക്കുന്നത് സേവനത്തിൽ കണക്കാക്കും; നിരസിക്കുന്നതോ
  അവഗണിക്കുന്നതോ വിട്ടുപോയ അപ്‌ഡേറ്റാണ്, പക്ഷേ അത് ദിവസം പൂർത്തിയാക്കുന്നത് ഒരിക്കലും തടയില്ല.
- **രാത്രി.** ആറാം ദിവസം മുതൽ ഓരോ മൂന്നാം ദിവസവും ഇരുട്ടിയതിനു ശേഷമാണ്. ഹെഡ്‌ലൈറ്റുകൾ ഇല്ലാതെ വാൻ നീങ്ങുന്നതിനു മുമ്പ്
  ക്യാബ് മുന്നറിയിപ്പ് നൽകും; ഇരുട്ടിൽ ഹെഡ്‌ലൈറ്റുകൾ ഇല്ലാതെ ഓടിച്ച ഓരോ ഘട്ടവും സുരക്ഷയ്ക്ക് എതിരായി കണക്കാക്കും. എതിരെ
  വരുന്ന ഹെഡ്‌ലൈറ്റുകൾ അൽപം കണ്ണഞ്ചിപ്പിക്കും; കുറഞ്ഞ ചലനം അത് ഒഴിവാക്കുന്നു (3D ലോകത്ത് **Esc** →
  **ക്രമീകരണങ്ങൾ → ആക്സസിബിലിറ്റി → കുറഞ്ഞ ചലനം ഓൺ ചെയ്യുക** (Settings → Accessibility → Turn reduced motion on),
  അല്ലെങ്കിൽ PC-യുടെ സ്വന്തം കുറഞ്ഞ ചലന ക്രമീകരണം).

രാത്രി റണ്ണുകളും വാനിന്റെ കേടുപാടും (ചുറ്റും നടന്നുള്ള പരിശോധനയുടെ റിപ്പോർട്ടുകൾ സഹിതം) ഓരോന്നും വെവ്വേറെ
**3D ജോലിദിന സഹായങ്ങൾ…** (3D workday aids…)-ൽ ഓഫാക്കാം, ഉദാഹരണത്തിന് ഒരിക്കലും വാൻ ഓടിച്ചിട്ടില്ലാത്ത ഒരു സംഘത്തിന്റെ
ആദ്യ സെഷനു വേണ്ടി.

ഇതെല്ലാം ചേരുമ്പോൾ ഒരു PC പതുക്കെയാണെങ്കിൽ, **ക്രമീകരണങ്ങൾ → ഗ്രാഫിക്സ് → കുറഞ്ഞ ഗ്രാഫിക്സ്** (Settings → Graphics → Low)
കുറച്ചു മാത്രം വരയ്ക്കുകയും ദിവസം അതേപടി നിലനിർത്തുകയും ചെയ്യുന്നു.

പരിശീലന മൊഡ്യൂളുകളും വിലയിരുത്തലുകളും ജോലിദിനത്തിനു മുമ്പോ ശേഷമോ ആകാം. നല്ലൊരു ക്രമം: കമ്പനിക്ക് ഏറ്റവും പ്രധാനപ്പെട്ട
മൊഡ്യൂളുകളിൽ ഒരു പരിശീലന സെഷൻ, പിന്നെ ജോലിദിനം, പിന്നെ വിലയിരുത്തലുകൾ.

## ഫലങ്ങൾ വായിക്കൽ

**പരിശീലനാർഥിയുടെ സ്ക്രീനിൽ**
- **ഫലങ്ങൾ** (Results): സുരക്ഷ, കാര്യക്ഷമത, സേവനം എന്നിവയിലെ നക്ഷത്രങ്ങളും സ്കോറും.
- **ഡീബ്രീഫ്** (Debrief): ഓരോ സ്റ്റോപ്പും, എന്ത് ശരിയായി അല്ലെങ്കിൽ തെറ്റായി ചെയ്തു, എന്തുകൊണ്ട്. ഗുരുതരമായ തെറ്റുകൾ
  (ഉദാഹരണത്തിന് ലൈറ്റുകൾ മിന്നുന്ന സ്കൂൾ ബസിനെ മറികടക്കുക, അല്ലെങ്കിൽ ID പരിശോധിക്കാതെ പ്രായപരിധിയുള്ള പാഴ്സൽ ആർക്കെങ്കിലും
  നൽകുക) ബാക്കിയെല്ലാം എത്ര നന്നായാലും ആ വിഭാഗത്തെ ഒരു നക്ഷത്രത്തിൽ ഒതുക്കും.
- **ഡ്രൈവ് മാപ്പ്** (Drive map): ഓരോ ഡ്രൈവിങ് തെറ്റും സംഭവിച്ചിടത്ത് ഒരു പിൻ, പാഠം സഹിതം.
- **അവസാനത്തെ തെറ്റ് വീണ്ടും പ്ലേ ചെയ്യുക** (Replay the last mistake) (3D ജോലിദിനത്തിനു ശേഷം, ഫലങ്ങളിലും ഡ്രൈവ് മാപ്പിലും):
  ഏറ്റവും ഒടുവിലത്തെ തെറ്റിനു മുമ്പുള്ള അവസാന ഏതാനും സെക്കൻഡുകൾ, ഡ്രൈവറുടെ സീറ്റിൽനിന്ന്, പ്ലേ, പോസ്, അര സെക്കൻഡ് ചുവടുകൾ
  എന്നിവയോടെ. ഇത് ബ്രൗസറിന്റെ മെമ്മറിയിൽ മാത്രമേ ഉള്ളൂ; അതിനാൽ ടാബ് അടയ്ക്കുമ്പോഴോ മറ്റൊരു ജോലിദിനം തുടങ്ങുമ്പോഴോ
  ഇല്ലാതാകും; അതിൽ ഒന്നും സേവ് ചെയ്യുകയോ പോയിന്റിനായി കണക്കാക്കുകയോ ഇല്ല.
- **എന്റെ റെക്കോർഡ് ›** (My record ›): ഓരോ മൊഡ്യൂളും തീയതികളും ആവർത്തിച്ചുവരുന്ന പാഠങ്ങളും. **പ്രിന്റ് / PDF** (Print / PDF)
  ഫയലിൽ സൂക്ഷിക്കാനുള്ള പേജ് നൽകുന്നു.

പരിശീലകന്റെ ഉപകരണങ്ങളും (**ക്രമീകരണങ്ങൾ → പരിശീലകൻ** (Settings → Trainer): വീണ്ടും ശ്രമിക്കാനുള്ള അനുമതി, റീസെറ്റ്,
മുമ്പും ശേഷവും, സർട്ടിഫിക്കറ്റ്, അവരുടെ ഡാറ്റ) LMS ഭാഗവും ഇംഗ്ലീഷ് ഗൈഡിലാണ്.
