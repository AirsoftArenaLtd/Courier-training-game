# પ્રશિક્ષકની ઝડપી શરૂઆત (એક પાનું)

સત્ર ચલાવનાર વ્યક્તિ માટે. આ પાનું છાપો; સંપૂર્ણ માર્ગદર્શિકા `docs/PILOT-GUIDE.md` છે.

**તાલીમાર્થીઓ આવે તે પહેલાં**
1. એક તાલીમ PC પર ગેમ ખોલો અને એક કામકાજનો દિવસ શરૂ કરો. જો "WebGL is required" દેખાય, તો IT ને ગ્રાફિક્સ ઍક્સિલરેશન ચાલુ કરવા કહો (`chrome://gpu` માં "WebGL: Hardware accelerated" દેખાવું જોઈએ).
2. **સેટિંગ્સ → પ્રશિક્ષક** (Settings → Trainer) (તમારો PIN): જો તાલીમાર્થીઓ કર્મચારી ID થી સાઇન ઇન કરતા હોય, તો ખાતાં બનાવો (**નવું ખાતું** (New account); કામચલાઉ પાસવર્ડ ફક્ત એક જ વાર દેખાય છે).
3. એ જ સ્ક્રીન પર: **અકાદમીના નિયમો** (Academy rules) (પાસ માર્ક, પ્રયાસો) અને **3D કામકાજના દિવસની સહાય…** (3D workday aids…) (ડ્રાઇવિંગ સહાય, નેવિગેશન, રાત્રિના રન, વૅનનું નુકસાન). "દિવસ મુજબ ઘટે" ("Fade by day") દિવસ 1 પર પૂરી મદદ આપે છે, દિવસ 2–3 પર ઓછી, અને દિવસ 4 થી થોડી. **નિયમો સેવ કરો** (Save rules) દબાવો.

**સત્ર (લગભગ એક કલાક)**

| સમય | શું |
| --- | --- |
| 10 મિનિટ | સ્વાગત. હેતુ સલામત ટેવો છે, ઝડપ નહીં; ભૂલો જ પાઠ છે. |
| 5 મિનિટ | સાઇન ઇન. **સેટિંગ્સ → ઍક્સેસિબિલિટી** (Settings → Accessibility): ભાષા, મોટું લખાણ, રંગો, કી, નરેશન. |
| 30 મિનિટ | દરેક તાલીમાર્થી એક **કામકાજનો દિવસ** (workday) રમે છે. રમતાં રમતાં તે સેવ થાય છે; પૉઝ મેનૂથી અટકીને પછી ફરી ચાલુ કરી શકાય છે. ફરી ચાલુ કરવા **એ જ કમ્પ્યૂટર** વાપરો; બીજા કમ્પ્યૂટર પર દિવસ સવારથી ફરી શરૂ થાય છે (ગેમ પહેલાં પૂછે છે: "આ કામકાજનો દિવસ બીજા કમ્પ્યૂટર પર શરૂ થયો હતો"). |
| 15 મિનિટ | સાથે મળીને ડિબ્રીફ: **પરિણામ → ડિબ્રીફ** (Results → Debrief), પછી **ડ્રાઇવનો નકશો** (drive map) અને **છેલ્લી ભૂલ ફરી ચલાવો.** (Replay the last mistake.) (ભૂલ પહેલાંની થોડી સેકન્ડ, ડ્રાઇવરની સીટ પરથી). પૂછો: સૌથી અઘરો સ્ટોપ કયો હતો, અને તમે શું અલગ કરત? |

**કૅબ બતાવો (એક મિનિટ)**
- **જુઓ:** અરીસો તપાસવા તેની તરફ જુઓ; ચાલતાં પહેલાં ડાબો અરીસો, વળતાં પહેલાં જે બાજુ વળો છો તે બાજુનો અરીસો.
- **સિગ્નલ:** ડાબે **Q**, જમણે **C**; આગળ વધતા (પાછળ જતાં પણ) કે વળતા પહેલાં ઓછામાં ઓછું ત્રણ સેકન્ડ, પછી અરીસો.
- **ગિયર:** સિલેક્ટર તરફ જુઓ અને **E** દબાવો, રિવર્સ માટે **R**; પાછળનો કૅમેરા આપમેળે ચાલુ થાય છે.
- ડૅશ પર **નેવિગેશન** (sat nav): રૂટ, આગળનો વળાંક અને કેટલું દૂર. વળાંક ચૂકી જાઓ તો રૂટ ફરી બને છે; 30 સેકન્ડમાં રૂટ પર પાછા આવો.
- **રસ્તાનાં ચિહ્નો:** સ્ટોપ ચિહ્ન, રસ્તો આપો, ઝડપ મર્યાદા, શાળા વિસ્તાર, એકમાર્ગી રસ્તો, પ્રવેશ નિષેધ, રસ્તાનું કામ, ટ્રાફિક લાઇટ.
  **J** સામે દેખાતું ચિહ્ન મોટેથી વાંચે છે.
- **H** કોઈ પણ સમયે નિયંત્રણો અને માર્ગદર્શન ખોલે છે; **P** કીબોર્ડથી કૅબનાં નિયંત્રણો એક પછી એક બતાવે છે.

**ચોથા કામકાજના દિવસથી** (શરૂ કરતાં પહેલાં કહો)
- **મુસાફરી પહેલાંની તપાસ** (Pre-trip walkaround): પહેલી ડ્રાઇવ પહેલાં વૅનની ચારે બાજુ ફરીને, અને છેલ્લા સ્ટોપ પછી ડેપો પર ફરીથી: કોઈ ભાગ સુધી **P**, **E**,
  પછી બંધબેસતું વર્ણન. પોતે કરેલો ઘસરકો નોંધે નહીં તો તે ગંભીર ભૂલ છે.
- **ડિસ્પેચ રેડિયો** (the dispatch radio) પહેલી ડ્રાઇવમાં એક વાર કૉલ કરે છે: ઊભા રહો, પાર્કિંગ બ્રેક લગાવો, પછી **હૅન્ડહેલ્ડ** (handheld) પર સંદેશ વાંચો.
- **રાત:** દિવસ 6 થી દર ત્રીજા દિવસે: ચાલતાં પહેલાં **હેડલાઇટ** (Headlights) (**L**) ચાલુ કરો.

**ડ્રાઇવનો નકશો વાંચવો:** દરેક ડ્રાઇવિંગ ભૂલ પર એક પિન. હીરો એટલે રસ્તાનું ચિહ્ન કે લાલ લાઇટ, તારો વૅનનું નુકસાન, ત્રિકોણ નીચો પુલ, ષટ્કોણ ખસી ગયેલો માલ, તીર ખોટો વળાંક, વત્તાનું ચિહ્ન કેબની ટેવ (સિગ્નલ, અરીસો, સીટબેલ્ટ કે હેડલાઇટ), અને વર્તુળ બાકીનું બધું. ગંભીર ભૂલો (લાલ લાઇટ, પ્રવેશ નિષેધ, સ્કૂલ બસ) તે શ્રેણીને એક તારા સુધી મર્યાદિત કરે છે.

**જ્યારે કંઈક ખોટું થાય**

| તમે શું જુઓ છો | શું કરવું |
| --- | --- |
| ધીમું કે અટકતું 3D | **સેટિંગ્સ → ગ્રાફિક્સ → ઓછા ગ્રાફિક્સ** (Settings → Graphics → Low); બીજાં ટૅબ બંધ કરો; લૅપટૉપ ચાર્જરમાં લગાવો. |
| સાઇન ઇન થતું નથી | ID તપાસો; પાંચ ખોટા પ્રયાસથી 15 મિનિટ માટે લૉક થાય છે; **વ્યવસ્થા → નવો પાસવર્ડ** (Manage → New password) તેને ખોલે છે. |
| પ્રગતિ ખોવાઈ ગઈ લાગે છે | કર્મચારી ID એ જ છે? સર્વર દરેક ID પ્રમાણે પ્રગતિ રાખે છે. |
| કોઈ ભાષામાં લખાણ ખોટું દેખાય છે | સ્ક્રીન અને શબ્દો નોંધીને માતૃભાષી સમીક્ષકોને આપો (`docs/review/`). |
| સર્વર બંધ છે | તાલીમાર્થીઓ રમતા રહે; સર્વર પાછું આવે ત્યારે પ્રગતિ મોકલાય છે. IT ને તેને રીસ્ટાર્ટ કરવા કહો. |
