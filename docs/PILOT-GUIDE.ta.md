# முன்னோட்டத் திட்டத்துக்கான பயிற்சியாளர் வழிகாட்டி

இந்தப் பக்கத்தில் பயிற்சி அறையில் பயிற்சியாளர் பயன்படுத்தும் பகுதிகள் மட்டுமே உள்ளன: அமர்வை நடத்துவது, வண்டியின் உள்ளே
(கண்ணாடிகள், சிக்னல்கள், கியர்கள், வழிகாட்டி, சாலை அடையாளங்கள்), பிந்தைய வேலை நாட்கள், முடிவுகளைப் படிப்பது, ஏதாவது
தவறாகும்போது என்ன செய்வது. IT மற்றும் சர்வர் அமைப்பு, கணக்குகள், அகாடமி விதிகள், நிறுவனத் தோற்றம், பயிற்சியாளர் கருவிகள்,
LMS, தரவு ஆகிய பகுதிகள் ஆங்கில வழிகாட்டியான `docs/PILOT-GUIDE.md`-இல் மட்டுமே உள்ளன. அச்சிட ஒரு பக்கம்: `docs/QUICK-START.ta.md`.

**பயிற்சி பெறுவோர் என்ன செய்கிறார்கள்.** அவர்கள் உள்நுழைந்து, பயிற்சித் தொகுதிகளில் (பிரித்தல், தூக்குதல், ஓட்டுதல்,
ஏற்றுதல், நிறுத்தங்கள்) பயிற்சி செய்து மதிப்பீடு பெறுகிறார்கள்; ஒரு **வேலை நாள்** (workday) விளையாடுகிறார்கள்: 3D-யில்
ஒரு கூரியரின் முழு நாள். டிஸ்பாட்சில் காலை விளக்கத்தைப் படித்து, சரக்கை மேனிஃபெஸ்ட்டுடன் ஒப்பிட்டுச் சரிபார்த்து, வேனில்
ஏற்றி, வேனைச் சோதித்து, ஓட்டி, ஐந்து நிறுத்தங்களில் டெலிவரி செய்கிறார்கள் (நாய்கள், கையொப்பங்கள், அடையாளச் சோதனைகள்,
தவறான முகவரிகள், வானிலை, டிஸ்பாட்சிலிருந்து வரும் செய்திகள்). டெலிவரி செய்ய முடியாதவற்றைத் திருப்பிக் கொடுத்து,
டிஸ்பாட்சில் நாளை முடிக்கிறார்கள். பாதுகாப்பு, திறன், சேவை ஒவ்வொன்றுக்கும் 0 முதல் 3 நட்சத்திரங்கள் வரை மதிப்பெண்
உண்டு. முதல் நாள் எளிதானது; ஒரு சிறிய வழிகாட்டல் (**H** மூலம் மீண்டும் திறக்கலாம்) கட்டுப்பாடுகளை விளக்குகிறது. பிந்தைய
நாட்கள் அதிகம் கேட்கின்றன: ஒவ்வொரு பார்சலுக்கும் கையொப்பம், புகைப்பட அடையாளச் சோதனைகள், நிர்ணயித்த அட்டவணைப்படி
மூடுபனி, மழை, பனிக்கட்டி, சாலைப் பணியால் மூடப்பட்டு மாற்றுப் பாதை உள்ள ஒரு தெரு. பிந்தைய நாட்களில் திட்டமிடல் சாளரங்கள்
வழிகாட்டல் மட்டுமே; அவற்றுக்கு ஒருபோதும் மதிப்பெண் கிடையாது. நாள் ஒரு முடிவுத் திரை, எது நன்றாக நடந்தது, எதைச் சரிசெய்ய
வேண்டும் என்று காட்டும் மறுஆய்வு, அச்சிடக்கூடிய ஒரு பதிவு ஆகியவற்றுடன் முடிகிறது.

## முதல் அமர்வுக்கு முன்

(1 முதல் 4 வரை: IT, கணக்குகள், அகாடமி விதிகள், நிறுவனத் தோற்றம்; ஆங்கில வழிகாட்டியைப் பாருங்கள்.)

**5. மொழியும் வசதியும்.** ஒவ்வொரு பயிற்சி பெறுநரும் **அமைப்புகள் → அணுகல்தன்மை** (Settings → Accessibility) பகுதியில்
தங்கள் மொழி, பெரிய எழுத்து, நிறக்குருடு அமைப்பு, விசை மாற்றம், குறைந்த இயக்கம், விவரிப்பு ஆகியவற்றைத்
தேர்ந்தெடுக்கலாம். ஒலிக்கு (என்ஜின், இண்டிகேட்டர்கள், கதவுகள், ஸ்கேன்கள், மழை) ஒலியளவும் முடக்கமும் உண்டு (ஸ்பீக்கர்
பொத்தான் அல்லது இடைநிறுத்த மெனு); ஒவ்வொரு ஒலிக்கும் ஓர் உரைத் தலைப்பும் உண்டு, விவரிப்பு பேசும்போது ஒலி நின்றுவிடும்;
எனவே விளையாட யாரும் அதைக் கேட்க வேண்டியதில்லை. ஒரு PC-யில் 3D சிரமப்பட்டால்,
**அமைப்புகள் → கிராஃபிக்ஸ் → குறைந்த கிராஃபிக்ஸ்** (Settings → Graphics → Low) என அமையுங்கள். தாய்மொழியாளர்கள் மதிப்பாய்வு
செய்யும் வரை மொழிபெயர்ப்புகள் இயந்திர வரைவுகளே (`docs/review/`); தவறாகத் தோன்றும் சொற்களைத் தெரிவிக்குமாறு பயிற்சி
பெறுவோரிடம் சொல்லுங்கள்.

**6. கேம்பேட்.** 3D உலகில் ஒரு சாதாரண (ஸ்டாண்டர்ட்) கேம்பேடும் வேலை செய்யும்: அதன் ஒரு பொத்தானை அழுத்தி, பிறகு எல்லாக்
கட்டுப்பாடுகளையும் விடுங்கள். **Esc → கட்டுப்பாடுகளும் வழிகாட்டலும் → கேம்பேட் கட்டுப்பாடுகள்** ஒவ்வொரு பொத்தானும் என்ன
செய்கிறது என்று காட்டும்; பயிற்சியாளர் எந்தப் பொத்தானையும் மாற்றலாம் அல்லது ஸ்டிக்கின் உணர்திறனை மாற்றலாம், அவர்களின்
தேர்வுகள் அவர்களின் முன்னேற்றத்துடன் சேமிக்கப்படும். விசைப்பலகையும் சுட்டியும் தொடர்ந்து வேலை செய்யும்.

**ஓட்டுவதற்கு முன், வண்டியின் உள்ளே.** 3D வேனின் கேபின் உண்மையான வேனைப் போலவே இயங்குகிறது; அதைக் காட்ட ஒரு நிமிடம்
செலவிடுவது பயனுள்ளது:

- **கண்ணாடிகள்** எப்போதும் இயக்கத்திலும் நேரலையிலும் இருக்கும். கண்ணாடிக்கென்று பொத்தான் இல்லை: பயிற்சி பெறுநர் ஒரு
  கண்ணாடியைச் சில கணங்கள் *பார்ப்பதன் மூலம்* சரிபார்க்கிறார். நகரத் தொடங்குவதற்குச் சற்று முன் இடது கண்ணாடியையும்,
  ஸ்டீயரிங்கைத் திருப்புவதற்குச் சற்று முன் திரும்பும் அல்லது பாதை மாறும் பக்கத்துக் கண்ணாடியையும் சரிபார்க்க வேண்டும்
  (ஒரு சரிபார்ப்பு சுமார் நான்கு விநாடிகளுக்குச் செல்லுபடியாகும்). ஒவ்வொன்றும் முடிவுகளில் குறிக்கப்படும்; தவறவிட்ட
  சரிபார்ப்பு ஓட்ட வரைபடத்தில் ஒரு குறியீடாகும்.
- **சிக்னல்கள்** (B-138): இடதுக்கு Q, வலதுக்கு C, அல்லது ஸ்டீயரிங் அருகில் உள்ள இண்டிகேட்டர் கைப்பிடி. ஒரு
  நிறுத்தத்துக்குப் பிறகு வேன் நகரும் முன்பும் (பின்னோக்கியும்) திரும்பும் முன்பும், இண்டிகேட்டர் சரியான திசையில்
  குறைந்தது மூன்று விநாடிகள் இயங்கியிருக்க வேண்டும்; பிறகு கண்ணாடிச் சரிபார்ப்பு. சிக்னல் இல்லாவிட்டாலோ தாமதமானாலோ
  ஓட்ட வரைபடத்தில் ஒரு குறியீடு வரும். இண்டிகேட்டர் தானாக அணையாது: விசையை மீண்டும் அழுத்துங்கள்.
- **கியர்கள்** ஸ்டீயரிங் அருகில் உள்ள P-R-N-D தேர்வியில் உள்ளன: அதைப் பார்த்துச் செயல் விசையை (E) அழுத்துங்கள், அல்லது
  Drive, Reverse இடையே மாற R அழுத்துங்கள். கியர் மாற்ற வேன் நின்றிருக்க வேண்டும்.

  நகரும் முன் கேபின் எச்சரிக்கும்; இருட்டில் அவை இல்லாமல் ஓட்டும் ஒவ்வொரு பகுதியும் பாதுகாப்பு மதிப்பெண்ணைக் குறைக்கும்.
  எதிரே வரும் முகப்பு விளக்குகள் சிறிது கண் கூச்சத்தைத் தரும்; குறைந்த இயக்கம் அதை நீக்கும் (3D உலகில் **Esc** →
  **அமைப்புகள் → அணுகல்தன்மை → குறைந்த இயக்கத்தை இயக்குங்கள்** (Settings → Accessibility → Turn reduced motion on), அல்லது
  PC-யின் சொந்தக் குறைந்த இயக்க அமைப்பு).

இரவு ஓட்டங்களையும் வேன் சேதத்தையும் (அதன் சுற்றிப் பார்க்கும் அறிக்கைகளுடன்) **3D வேலைநாள் உதவிகள்…** (3D workday aids…)
பகுதியில் தனித்தனியாக அணைக்கலாம்; எடுத்துக்காட்டாக, வேன் ஓட்டியதே இல்லாத ஒரு குழுவுடன் நடக்கும் முதல் அமர்வுக்கு.

இவை அனைத்துடனும் ஒரு PC மெதுவாக இருந்தால், **அமைப்புகள் → கிராஃபிக்ஸ் → குறைந்த கிராஃபிக்ஸ்** (Settings → Graphics → Low)
குறைவாக வரைந்து அதே நாளைத் தக்கவைக்கும்.

பயிற்சித் தொகுதிகளும் மதிப்பீடுகளும் வேலை நாளுக்கு முன்போ பின்போ வரலாம். நல்ல வரிசை: நிறுவனம் மிக முக்கியமாகக் கருதும்
தொகுதிகளில் ஒரு பயிற்சி அமர்வு, பிறகு வேலை நாள், பிறகு மதிப்பீடுகள்.

## முடிவுகளைப் படித்தல்

**பயிற்சி பெறுநரின் திரையில்**
- **முடிவுகள்** (Results): பாதுகாப்பு, திறன், சேவை ஆகியவற்றில் நட்சத்திரங்களும் மதிப்பெண்ணும்.
- **மறுஆய்வு** (Debrief): ஒவ்வொரு நிறுத்தமும், அதில் எது சரியாக அல்லது தவறாகச் செய்யப்பட்டது, ஏன் என்பதுடன். கடுமையான
  தவறுகள் (எடுத்துக்காட்டாக, விளக்குகள் ஒளிரும் பள்ளிப் பேருந்தைக் கடந்து செல்வது, அல்லது வயது வரம்புள்ள பார்சலை அடையாளம்
  சரிபார்க்காமல் ஒருவரிடம் கொடுப்பது) மற்றவை எவ்வளவு நன்றாக நடந்தாலும் அந்தப் பிரிவை ஒரு நட்சத்திரத்துடன் நிறுத்தும்.
- **ஓட்ட வரைபடம்** (Drive map): ஒவ்வொரு ஓட்டத் தவறும் நடந்த இடத்தில் ஒரு குறியீடு, அதன் பாடத்துடன்.
- **கடைசித் தவறை மீண்டும் இயக்குங்கள்** (Replay the last mistake) (3D வேலை நாளுக்குப் பிறகு, முடிவுகளிலும் ஓட்ட
  வரைபடத்திலும்): சமீபத்திய தவறுக்கு முந்தைய கடைசிச் சில விநாடிகள், ஓட்டுநர் இருக்கையிலிருந்து; இயக்கு, இடைநிறுத்து, அரை
  விநாடி படிகள் உண்டு. அது உலாவியின் நினைவகத்தில் மட்டுமே இருக்கும்; எனவே tab மூடப்பட்டதும் அல்லது வேறொரு வேலை நாள்
  தொடங்கியதும் அது போய்விடும்; அதில் எதுவும் சேமிக்கப்படுவதுமில்லை, மதிப்பெண்ணில் சேர்வதுமில்லை.
- **என் பதிவு ›** (My record ›): ஒவ்வொரு தொகுதியும், தேதிகளும், மீண்டும் மீண்டும் வரும் பாடங்களும். **அச்சிடு / PDF**
  (Print / PDF) கோப்பில் வைக்க அந்தப் பக்கத்தைத் தரும்.

பயிற்சியாளருக்கான கருவிகள் (**அமைப்புகள் → பயிற்சியாளர்** (Settings → Trainer): மீண்டும் எழுத அனுமதி, மீட்டமைத்தல், முன்பும்
பின்பும், சான்றிதழ், அவர்களின் தரவு) மற்றும் LMS பற்றிய பகுதி ஆங்கில வழிகாட்டியில் உள்ளன.

## ஏதாவது தவறாகும்போது

| நீங்கள் பார்ப்பது | செய்ய வேண்டியது |
| --- | --- |
| பயிற்சி பெறுநரால் உள்நுழைய முடியவில்லை | ஊழியர் ID-யைச் சரிபாருங்கள் (பெரிய, சிறிய எழுத்து வேறுபாடு முக்கியமில்லை). ஐந்து தவறான முயற்சிகள் அதை 15 நிமிடம் பூட்டும்; **நிர்வகி → புதிய கடவுச்சொல்** (Manage → New password) உடனே பூட்டைத் திறக்கும். |
| விளையாட்டு தொடங்கவில்லை, அல்லது "WebGL is required" | கிராஃபிக்ஸ் முடுக்கம் அணைக்கப்பட்டுள்ளது அல்லது தடுக்கப்பட்டுள்ளது. `chrome://gpu` (Edge: `edge://gpu`) திறந்து "WebGL: Hardware accelerated" என்று உள்ளதா எனப் பாருங்கள். அதை இயக்குமாறு IT-யிடம் கேளுங்கள்; **அமைப்புகள் → கிராஃபிக்ஸ் → குறைந்த கிராஃபிக்ஸ்** (Settings → Graphics → Low) முயன்று பாருங்கள். |
| 3D மெதுவாக அல்லது தடுமாறி இயங்குகிறது | **அமைப்புகள் → கிராஃபிக்ஸ் → குறைந்த கிராஃபிக்ஸ்** (Settings → Graphics → Low); மற்ற சாளரங்களையும் tab-களையும் மூடுங்கள்; லேப்டாப்பை மின்சாரத்தில் இணையுங்கள். PC மாடலை விளையாட்டுப் பராமரிப்பாளரிடம் சொல்லுங்கள்: முன்னோட்டத் திட்டம் உண்மையான PC-களை அளவிடுகிறது. |
| கேம்பேடால் எதுவும் நடக்கவில்லை | 3D உலகம் திறந்திருக்கும்போது அதன் ஒரு பொத்தானை அழுத்தி, பிறகு எல்லாக் கட்டுப்பாடுகளையும் விடுங்கள். உலாவி ஸ்டாண்டர்ட் என்று அறியும் கேம்பேடுகள் மட்டுமே வேலை செய்யும்; விசைப்பலகையும் சுட்டியும் எப்போதும் வேலை செய்யும். **கேம்பேட் கட்டுப்பாடுகள் → கேம்பேடின் இயல்புநிலை கட்டுப்பாடுகளை மீட்டமைக்கவும்** மாற்றிய பொத்தான்களைப் பழையபடி ஆக்கும். |
| முன்னேற்றம் இழந்தது போல் தெரிகிறது | பயிற்சி சர்வரில் அது ஒவ்வொரு ஊழியர் ID-க்கும் தனியாக வைக்கப்படுகிறது: அவர்கள் அதே ID-யுடன் உள்நுழைந்தார்களா என்று சரிபாருங்கள். உலாவி மட்டும் பயன்முறையில் முன்னேற்றம் அந்த உலாவியிலேயே இருக்கும்; அதன் தளத் தரவை அழித்தால் அதுவும் அழியும். |
| ஒரு மொழியில் உரை தவறாகத் தெரிகிறது | திரையையும் உரையையும் குறித்துக்கொள்ளுங்கள்; திருத்தங்கள் `docs/review/`-இல் உள்ள தாய்மொழி மதிப்பாய்வுத் தாள்களுக்குச் செல்லும். |
| ஒரு பயிற்சி பெறுநர் தம் தரவை நீக்கச் சொல்கிறார் | **அமைப்புகள் → பயிற்சியாளர்** (Settings → Trainer) → அந்தப் பயிற்சி பெறுநர் → **அவர்களின் தரவு** (Their data). |
| சர்வர் செயலிழந்துள்ளது | பயிற்சி பெறுவோர் தொடர்ந்து விளையாடலாம்: முன்னேற்றம் அவர்களின் PC-யில் வைக்கப்பட்டு, சர்வர் பதிலளிக்கும்போது அனுப்பப்படும். `node server/server.js`-ஐ மறுதொடக்கம் செய்யுமாறு IT-யிடம் கேளுங்கள்; எதுவும் இழக்கப்படாது. |

## யாரைத் தொடர்புகொள்வது

முன்னோட்டத் திட்டத்துக்காக இவற்றை நிரப்புங்கள்:

- நிறுவனத்தின் பயிற்சித் தலைவர்: ______________________
- பயிற்சி சர்வருக்கும் PC-களுக்கும் IT: ______________________
- விளையாட்டுப் பராமரிப்பாளர் (பிழைகள், சொற்கள், நிறுவனத் தீம்): ______________________

ஒரு சிக்கலைத் தெரிவிக்கும்போது, பயிற்சி பெறுநரின் ஊழியர் ID (கடவுச்சொல் அல்ல), அவர் என்ன செய்துகொண்டிருந்தார், நேரம்,
திரை ஆகியவற்றைச் சொல்லுங்கள். ஒரு ஸ்கிரீன்ஷாட் உதவும்.
