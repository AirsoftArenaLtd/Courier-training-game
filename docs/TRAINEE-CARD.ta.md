# On The Route: உங்கள் முதல் நாள் (ஒரு பக்கம்)

பயிற்சியாளர்களுக்கானது. முழு வழிகாட்டி உங்கள் பயிற்றுநரிடம் உள்ளது; தொடங்க உங்களுக்கு வேண்டியது இதுவே.

**உள்நுழைதல்**
- உங்கள் ஊழியர் ஐடி (Employee ID) மற்றும் பயிற்றுநர் தரும் கடவுச்சொல்லை (Password) உள்ளிடுங்கள். முதல்முறை உங்கள் சொந்தக் கடவுச்சொல்லை நீங்களே தேர்ந்தெடுப்பீர்கள்.
- ஐந்து தவறான கடவுச்சொற்கள் கணக்கை 15 நிமிடம் பூட்டும்; உங்கள் பயிற்றுநர் உடனே திறக்க முடியும்.
- **அமைப்புகள் → அணுகல்தன்மை** (Settings → Accessibility): மொழி, பெரிய எழுத்து, நிறங்கள், விசைகள், விவரிப்பு (விளையாட்டு திரையை உரக்கப் படிக்கும்).

**நட்சத்திரங்கள் என்ன சொல்கின்றன**

ஒவ்வொரு தொகுதியும் ஒவ்வொரு வேலைநாளும் **பாதுகாப்பு** (safety), **திறன்** (efficiency), **சேவை** (service) ஆகியவற்றில் 0 முதல் 3 நட்சத்திரங்கள் தரும். ஒரு **கடுமையான** (critical) தவறு (எடுத்துக்காட்டு: சிவப்பு விளக்கைத் தாண்டிச் செல்வது, நுழையத் தடையுள்ள தெருவில் நுழைவது, விளக்குகள் மின்னும் பள்ளிப் பேருந்தைக் கடப்பது, அல்லது அடையாள அட்டையைச் சரிபார்க்காமல் வயது வரம்புள்ள பார்சலைக் கொடுப்பது) மற்றவை எவ்வளவு நன்றாக நடந்தாலும் அந்தப் பிரிவை ஒரு நட்சத்திரத்துடன் நிறுத்தும்.
தவறுகளே பாடம்: ஒவ்வொரு நாளுக்கும் பிறகு வரும் **மறுஆய்வு** (Debrief) எது நன்றாக நடந்தது, எதைத் திருத்த வேண்டும் என்று காட்டும்; **ஓட்ட வரைபடம்** (drive map) ஒவ்வொரு ஓட்டத் தவறும் நடந்த இடத்தில் ஒரு குறியீட்டை வைக்கும்.

**3D வேலைநாளில்**

| விசை | என்ன செய்யும் |
| --- | --- |
| **W A S D** அல்லது அம்புக்குறிகள் | நடக்க; வண்டியில் ஓட்டவும் திருப்பவும் |
| **E** | நீங்கள் பார்ப்பதைப் பயன்படுத்த (கதவு, பார்சல், வண்டியில் ஒரு கட்டுப்பாடு) |
| **P** | அருகில் பயன்படுத்தக்கூடியவற்றை விசைப்பலகையிலிருந்து ஒவ்வொன்றாகத் தேர்ந்தெடுக்க |
| **H** | மெனு: **கட்டுப்பாடுகளும் வழிகாட்டலும்** (Controls and guidance), **அமைப்புகள்** (Settings), **பணிநாள் படிகள்** (Workday steps) |

| **B** / **Space** | சீட்பெல்ட் (Seatbelt) / பார்க்கிங் பிரேக் (Parking brake) |

| **L** / **K** | முகப்பு விளக்குகள் / வைப்பர்கள் |
| **J** | நீங்கள் பார்க்கும் சாலை அடையாளத்தை உரக்கப் படிக்க |

**விளையாட்டு எதிர்பார்க்கும் நல்ல பழக்கங்கள்**
- நகரும் முன் இடது கண்ணாடியைப் பாருங்கள்; திரும்பும் பக்கக் கண்ணாடியை ஸ்டீயரிங் திருப்பும் முன் பாருங்கள்.
- டேஷ்போர்டில் உள்ள **வழிகாட்டியை** (Sat nav) பின்பற்றுங்கள். நிறுத்தக் குறியில் முழுமையாக நில்லுங்கள், குறி சொல்லும் இடத்தில் வழிவிடுங்கள், வேக வரம்பைப் பின்பற்றுங்கள்.
- சிவப்பு விளக்கில் நில்லுங்கள். வலதுபுறம் சைக்கிள் ஓட்டுநர்களையும், பள்ளிக் கடவில் குழந்தைகளையும் கவனியுங்கள்.
- ஓட்டும் முன் சுமையைக் கட்டுங்கள் (secure the load), அதனுடன் மென்மையாக ஓட்டுங்கள். உங்கள் வேனின் உயரம் 10 அடி 10 அங்குலம்: தாழ்வான பாலங்களைத் தவிருங்கள்.
- ஒவ்வொரு வாசலிலும்: சரியான பார்சல், ஸ்கேன் செய்தது, பார்சலுக்குத் தேவையான சரிபார்ப்புகள் (கையொப்பம், புகைப்பட ID).

**பாதியில் நிறுத்துதல்**
வேலைநாள் விளையாடும்போதே சேமிக்கப்படும். நிறுத்த, மெனுவைத் (**H**) திறந்து **சேமித்து மையத்துக்குத் திரும்பு** (Save and return to hub) என்பதைத் தேர்ந்தெடுங்கள். நிறுத்திய இடத்திலிருந்து தொடர **அதே கணினியில்** வாருங்கள்: வேறொரு கணினியில் நாள் காலையிலிருந்து மீண்டும் தொடங்கும் (விளையாட்டு முதலில் கேட்கும்).

**உதவி வேண்டுமா?** 3D வேலைநாளில் **H** அழுத்துங்கள், அல்லது உங்கள் பயிற்றுநரிடம் கேளுங்கள்.
