# Guide de démarrage rapide du formateur (une page)

Pour la personne qui anime la séance. Imprimez cette page ; le guide complet est `docs/PILOT-GUIDE.md`. (A4: `docs/print/QUICK-START.fr.html`)

**Avant l'arrivée des stagiaires**
1. Ouvrez le jeu sur un PC de formation et lancez une journée de travail. Si le message "WebGL is required" s'affiche, demandez à l'informatique d'activer l'accélération graphique (`chrome://gpu` doit indiquer "WebGL: Hardware accelerated").
2. **Réglages → Formateur** (Settings → Trainer) (votre PIN) : créez des comptes si les stagiaires se connectent avec un identifiant d'employé (**Nouveau compte** (New account) ; le mot de passe temporaire ne s'affiche qu'une fois).
3. Sur le même écran : **Règles de l'académie** (Academy rules) (note de réussite, tentatives) et **Aides de la journée 3D…** (3D workday aids…) (aides à la conduite, GPS, tournées de nuit, dégâts du fourgon). « Dégressif » ("Fade by day") donne une aide complète le jour 1, moins les jours 2–3 et très peu à partir du jour 4. Appuyez sur **Enregistrer les règles** (Save rules).

**La séance (environ une heure)**

| Durée | Contenu |
| --- | --- |
| 10 min | Accueil. L'objectif, ce sont les bons réflexes de sécurité, pas la vitesse ; les erreurs font partie de l'apprentissage. |
| 5 min | Connexion. **Réglages → Accessibilité** (Settings → Accessibility) : langue, texte plus grand, couleurs, touches, narration. |
| 30 min | Chaque stagiaire joue une **journée** (workday). La progression est enregistrée au fur et à mesure ; le menu de pause permet de s'arrêter et de reprendre plus tard. Pour reprendre, utilisez **le même ordinateur** ; sur un autre ordinateur, la journée recommence depuis le matin (le jeu demande d'abord). |
| 15 min | Débriefing collectif : **Résultats → Débriefing** (Results → Debrief), puis la **Carte de conduite** (drive map) et **Revoir la dernière erreur.** (Replay the last mistake.) (les secondes qui la précèdent, depuis le siège du conducteur). Demandez : quel arrêt était le plus difficile, et que feriez-vous autrement ? |

**Montrez-leur la cabine (une minute)**
- **Regarder :** regardez un rétroviseur pour le vérifier ; le rétroviseur gauche avant de démarrer, celui du côté où l'on tourne avant de braquer.
- **Clignotant :** **Q** à gauche, **C** à droite, au moins trois secondes avant de partir (en marche arrière aussi) ou de tourner, puis le rétroviseur.
- **Vitesses :** regardez le sélecteur et appuyez sur **E**, ou sur **R** pour la marche arrière ; la caméra arrière s'allume toute seule.
- **GPS** (sat nav) sur le tableau de bord : l'itinéraire, le prochain virage et la distance. Un virage manqué recalcule l'itinéraire ; reprenez-le dans les 30 secondes.
- **Panneaux de signalisation :** stop, cédez le passage, limitations de vitesse, zones scolaires, sens unique, sens interdit, travaux, feux tricolores.
  **J** lit à voix haute le panneau visible.
- **H** ouvre les commandes et l'aide à tout moment ; **P** parcourt une à une les commandes de la cabine au clavier.

**À partir de la quatrième journée** (prévenez-les avant de commencer)
- **Tour de vérification avant départ** (Pre-trip walkaround) du fourgon avant la première conduite, puis de nouveau au dépôt après le dernier arrêt : **P** jusqu'à une zone, **E**,
  puis la description qui correspond. Une éraflure qu'ils ont causée et qu'ils ne signalent pas est une erreur critique.
- **La radio du répartiteur** (the dispatch radio) appelle une fois pendant la première conduite : arrêtez-vous, serrez le frein à main, puis lisez le message sur le **Terminal** (handheld).
- **Nuit :** un jour sur trois à partir du jour 6 : allumez les **Phares** (**L**) avant de démarrer.

**Lire la carte de conduite :** un repère à chaque erreur de conduite. Un losange est un panneau ou un feu rouge, une étoile un dégât sur le fourgon, un triangle un pont bas, un hexagone un chargement déplacé, une flèche un mauvais virage, une croix un réflexe en cabine (clignotant, rétroviseur, ceinture ou phares), un cercle tout le reste. Les erreurs critiques (un feu rouge, un sens interdit, un bus scolaire) limitent cette catégorie à une étoile.

**En cas de problème**

| Ce que vous voyez | Que faire |
| --- | --- |
| 3D lente ou saccadée | **Réglages → Graphismes → Graphismes bas** (Settings → Graphics → Low) ; fermez les autres onglets ; branchez l'ordinateur portable sur le secteur. |
| Impossible de se connecter | Vérifiez l'identifiant ; cinq essais erronés le bloquent 15 minutes ; **Gérer → Nouveau mot de passe** (Manage → New password) le débloque. |
| La progression semble perdue | Est-ce le même identifiant d'employé ? Le serveur conserve la progression par identifiant. |
| Le texte semble incorrect dans une langue | Notez l'écran et les mots pour les relecteurs natifs (`docs/review/`). |
| Le serveur est hors service | Les stagiaires continuent de jouer ; la progression est envoyée à son retour. Demandez à l'informatique de le redémarrer. |
