# Original cab material draft

This is a project-made source texture produced with the image generation tool from a written material brief and no third-party image. Provenance and its exact SHA-256 are in `cab-plastic-original.json`. It remains outside the runtime manifest: its 1254-pixel PNG source is 3.8 MiB, above the runtime texture file limit, so C-49 must pack and encode it into the bounded High material atlas before the game can use it. It is project-owned, shipped under the game's licence. No external CC0 licence is claimed.
