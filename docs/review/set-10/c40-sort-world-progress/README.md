# C-40 conveyor component progress

This component is not loaded by index and has no production adapter yet. It adds a conveyor, physical numbered routing keys, matching destinations, a jam-reset post and a fixed pool of sixteen parcels. Three instanced batches share local geometry; printed numerals and parcel markings use coloured face geometry. No image map, font texture, extra pass or external artwork is added.

Four Node cases pass: fixed buffer/object identity over 1,000 updates, every active routing key through the five original waves, real depot clearance/ray reach, and idempotent disposal with shared geometry retained. The component-only all-parcel fixture stays below 1,700 triangles. The controller, combined Low/High gate, accessible/native workflow and visual captures are still required before this can be wired or accepted. Exact source hashes and log are in manifest.json. C-40 remains doing.
