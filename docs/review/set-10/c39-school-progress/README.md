# C-39 school-zone components — development only

The optional `m1-school` core and adapter source use the real school street, school-zone signs, live bus and crossing controller. They are unloaded: there is no new index tag, shared registry entry or default change on the pushed branch. The separate controllable-driving candidate remains frozen at `bf3cbb8b` while its browser acceptance runs. `registry-school.patch` is a proposal for Claude's A-30; the shared registry itself is untouched.

Thirteen Node cases pass: seven core, four adapter/controls and two bay-marking cases. The core includes a continuous motor-driven safe approach with the live bus/children, plus an unsafe actual crossing contact that produces the exact catalogue critical penalty. Other checks cover the four B-135 types, deduplication, whole-van parking, missing obligations, pause, local report routing and no workday writes. The two positive checks retain their catalogue maxima of two points each (400 maximum score); passing the flashing bus or contacting children retains the catalogue's four-point critical penalty. No new report type exists.

The controls use the physical mounted screen or the same remappable finish key. PRND controls, mirrors, automatic reverse camera and optional keyboard cab controls stay available. The independent road-marking helper draws four white strips with one reused mesh (48 triangles), no new texture or floating text, at the actual graded bay bounds. Its world/index hooks are still being developed separately, so the pushed prototype does not yet display those markings.

A proposed completion gate requires encountering both road hazards and parking the actual stopped van in the finish bay beyond the zone. Incomplete/expired drives produce zero score and safety ratio, retaining the observed log. Claude's confirmation is requested on the board before this optional scenario's shared academy entry lands. This policy is confined to the new optional scenario and changes no existing score scale.

Browser input, screenshots, accessibility and resource acceptance are pending. Resource fixtures are source only and have not run in a browser. No new geometry or texture is loaded at this stage. No Intel FPS or playable-school claim is made. O-1 remains the owner's measurement. Shared scoring/save/Settings/i18n files and the permanent hourly automation are unchanged.
