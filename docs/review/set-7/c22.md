The route, cargo and stationary starting position are fixtures. Target selection turns the view to the actual
raycastable control; every physical action in the browser flow uses the action key. The clip records the first
English run. New whole English instructions await Claude's translation, so the Tamil layouts show their English
fallback alongside existing Tamil interface text. Installed Noto fonts are used to measure Tamil glyphs.

The controls share the stopped-only gear interlock, physical/keyboard state and approved `drive.gear` reports.
Successful changes and rejected unsafe opposite-direction attempts have distinct keys that survive a checkpoint.
Park holds; Neutral coasts without engine force or reverse creep. No shared Settings/save/i18n/scoring source changed.

This is a procedural cab model while O-3's full packs remain pending; C-28 owns the exterior van/character asset
pass. Headlight and wiper switches preserve their state for C-25/C-26's lighting and windscreen animation.
The detailed model, tests and default/remappable keys are in `docs/3D-CAB.md`; commands and resource figures are in
`docs/PERF.md`. SwiftShader verifies behaviour and resource counters; O-1 still needs native Intel FPS.
