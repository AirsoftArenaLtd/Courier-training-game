# C-47: a smaller workday display

18 October 2026. `codex/c47-less-screen` is stacked on pushed C-28 `5c8279b`, over B-30
and pilot `951ef36`. Claude merges the stack in that order.

The workday no longer has a persistent title/objective bar or full-width key footer. The existing
physical gauges and switches keep their state. The dashboard mount now shows the generated streets,
van and destination; looking away clears it, and reverse automatically replaces it with the live
rear camera. The overview respects the trainer's sat-nav-off setting. P selects and narrates the
screen's current content. C-31 still supplies turn-by-turn routing after C-30's street signs.

The handheld adds **Read the workday details.** after the existing choices, retaining all their
key numbers. It contains the complete former objective, cargo count and carried address; Stop
details retains the service requirements and recorded shelf. Parking remains required to use it.
Each selected shifter position now confirms its state: for example, **Reverse is selected.**
Selecting it again still adds no scoring event.

A small wrapped prompt fades after 7–16 seconds, allowing for translated reading time. A target
change/action or closing a panel restores it; P can recall it. Reduced motion changes opacity
without interpolation. First-day key guidance remains full-size; later days keep it in the guide.
Actual safety/dispatch/break/storage warnings and audible captions stay available independently
of whichever control is selected. Night headlight and required practice walk-around prompts remain.
The bounded B-30 speech queue, automatic camera, mirrors, keyboard routes, colour filter, scores,
trainer aids, saved state and resume behavior are retained.

The implementation is in `src/core/fphud.js`; design/runtime notes are in `docs/3D-HUD.md`.
Shared `index.html` only adds its script. No shared scoring, save, Settings or i18n source is edited.
New whole English display sentences/templates need Claude's extraction and translation, including
four selected-gear confirmations, first-day key guidance, navigation context and handheld details.

## Reproduction

Serve the checkout and set `QA_BASE` to its URL; set `QA_BROWSER` to your Chromium executable.
Only one browser suite runs at a time. This environment uses `/usr/bin/chromium` and a local
Puppeteer installation via `NODE_PATH`.

```sh
node test/fphud.js
node test/fpcab.js
node test/fphandheld.js
node test/fpmission.js
node test/fpworld.js
node test/workday.js
node test/savesize.js
node test/i18n.js
node test/credits.js
node test/fphudbrowser.js
QA_FONT=noto node test/fpaccesslayout.js
node --test test/package.js
```

For matched captures, also serve the unchanged C-28 checkout and set `QA_BEFORE_BASE` to it;
`QA_BEFORE_REF=5c8279b QA_REF=10c1afb node test/fphudcomparebrowser.js` captures two
identical live camera/weather/seed fixtures, in normal English and larger Tamil.

Rendered view lists and accessibility flags are preserved in `c47/gates.json`. Use `QA_ACTORS=1
QA_TOWN=1 QA_LIGHTING=1 QA_WEATHER=1 QA_PROTOTYPE_ONLY=1 QA_SHOTS=1 QA_TAG=c47` with
`node test/fpbench.js`, setting `QA_GFX`, `QA_VIEWS` and `QA_A11Y` to the recorded run.
