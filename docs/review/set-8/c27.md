# C-27: the town asset pass

17 October 2026, `codex/c27-town-assets`, based on pilot `3c92bb0` after C-26 merged.
Locally bundled CC0 models replace non-delivery scenery. Customer facades, public paths,
collision boundaries, generated routes, scores, controls and saves retain their existing behaviour.
Low uses small models within a fixed detail allowance; High retains the source detail.

The tour uses day one, seed seven, a clear midday preset and stationary walking viewpoints. Travel,
clock and camera positions are fixtures. Each comparison hides only the named template type, requires
visible changed pixels and checks unchanged mission snapshots, reports and clean GL state. It does not
use the presence of a loaded file as proof of visible art. The asset/fallback clip keeps the same view.
Control, doorstep, full-route and keyboard flows exercise real interactions separately from these fixtures.

Props stay in the private front yards of already-solid non-delivery lots, outside their buildings. The
original lot footprint still blocks walking/driving; these yards are not new delivery destinations.
Node bounds/raycast tests preserve the existing public access and delivery targets. Reflection tests
restore every static/asset matrix, colour, count and visibility after all four reflection passes.

The four Kenney packs keep their original author licence bytes, including original line endings and
whitespace, and source/conversion hashes. Raw zips are not shipped. The owner-supplied Poly Haven texture
archives omit a licence record; Claude's inbox has the follow-up for B-1. Those files are not shipped.
Road/kerb detail uses Kenney palette geometry and anchored procedural grain, with no new image texture.

The unchanged Low ceilings are 64 calls, 2,500 triangles, two Three.js textures, 4 MiB attachments and
4 MiB estimated Phaser textures at 1280 × 720. `docs/PERF.md` has actual figures and commands;
`docs/3D-TOWN-ASSETS.md` describes conversion, placement and fallback. `c27-preparation.md` is historical.
The native Intel 60 fps check remains O-1; software-rendered FPS does not establish it.

A five-minute owner review:

1. Compare the Low and High house, car and road images; check that the objects form a coherent street.
2. Watch the same-view fallback clip; the workday should remain usable when files are missing.
3. Check the night/reversing images for live mirrors, rear camera and legible instruments.
4. Try a customer path, gate and front door with keyboard controls and larger text.
5. Measure Low on the Intel laptop using the existing native benchmark instructions in `docs/FRAME-BUDGET.md`.
